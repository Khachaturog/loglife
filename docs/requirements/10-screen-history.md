# 10. Экран: история записей

## Назначение

Блок «история записей»: список записей по выбранному делу с датой/временем и возможностью просмотра ответов каждой записи. Отображается на **странице просмотра дела** ([14-screen-deed-view.md](14-screen-deed-view.md)); при необходимости может быть вынесен в отдельный экран.

## Элементы экрана

- **Запись дела** — располагается в хронологии по времени, содержит дату, время и значение в превью-форме.
- **Заголовок группы по дате** — «Сегодня · 8 октября (чт)», «Вчера · …», «Позавчера · …»; для более ранних дней — «5 октября (пн)». Если дата не в текущем календарном году, в строке есть год: «31 декабря 2025 (ср)». Тот же формат на вкладке «История» и в блоке истории на странице дела.
- **Навигация назад** — возврат к списку дел или к карточке данного дела.

## Сценарии

1. Пользователь открывает дело (страница просмотра дела) — видит блок истории записей по этому делу.
2. В списке видит все свои записи с датой, временем и превью.
3. Открывает любую запись и просматривает полные ответы и служебные поля (дата, время, заметки); при необходимости редактирует их.

## Вкладка «История» (маршрут `/history`)

Отдельный экран со списком записей по всем делам. Сначала загружаются **последние 7 календарных дней** (включая сегодня). Если есть более старые записи, внизу списка кнопка **Показать раньше**: она догружает следующую порцию в **30 календарных дней**, заканчивающуюся ближайшей ещё не показанной датой. Та же порция подгружается, когда низ списка доскроллили до видимой области; пока пользователь не проскроллил, короткий список сам всю историю не забирает. Бейдж в шапке — общее число записей, а не только загруженных. Блок истории на странице дела по-прежнему показывает все записи этого дела.

Переход на просмотр записи (`/records/:id`) передаёт в location state признак `from: 'history'`, чтобы на экране записи показывать действие **переход к делу** (быстрый переход на страницу этого дела). Если запись открыта с **страницы дела** или иначе без этого признака, кнопка «к делу» в шапке не показывается — контекст уже привязан к делу или отличается.

На экране записи (`/records/:id`) в AppBar при просмотре заголовок «Запись», при редактировании — «Редактирование». В шапке просмотра — закреплённые для этого дела действия (по умолчанию **Редактировать**), при открытии из истории ещё кнопка **к делу**, и меню **⋯** со всеми действиями записи, пунктом «Перейти к делу» и «Настроить действия».

В списках карточек записей (вкладка «История» и блок истории на странице дела) доступно **контекстное меню**: на тач-устройствах — **long tap** по карточке, в веб-браузере — **правая кнопка мыши** по карточке. Пункты: **Перейти к делу** (страница просмотра дела записи), **Новая запись** (пустая форма заполнения для того же дела), **Дублировать** (форма с копией ответов), **Редактировать** (запись сразу в режиме правки), **Удалить** (диалог подтверждения: фокус на кнопке удаления, **Enter** подтверждает, **Escape** отменяет). Короткий тап / левый клик по-прежнему открывает просмотр записи.
