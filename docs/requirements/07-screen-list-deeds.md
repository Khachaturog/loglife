# 07. Экран: список дел

## Назначение

Главный экран (или один из основных), на котором пользователь видит все свои дела в виде карточек и может перейти к созданию, редактированию, заполнению формы или просмотру истории.

## Элементы экрана

- **Список карточек дел** — каждая карточка отображает эмодзи/символ и название. Число за сегодня — та же метрика, что раньше в «N сегодня»: для дел только с «Да/Нет», текстом, выбором и т.п. это **количество записей** за сегодня; если в деле есть числовой блок — сумма или количество записей по правилам блоков. Счётчик «всего» на списке дел не считается и не показывается. Если за сегодня 0, в списке только название; если больше нуля — под названием серое число без слова «сегодня».
- **Сортировка списка** — в шапке экрана кнопка с меню: **по умолчанию** (порядок как после загрузки с сервера, новые выше по `created_at`) и **по количеству сегодня**, по убыванию; метрика — то же число за сегодня, что на карточке. Пока не пришёл второй запрос (записи только за сегодняшний день), упорядочивание по числу временно некорректно (все считаются без данных), после загрузки применится выбранный режим. Режим сохраняется в **`localStorage` браузера** и после обновления страницы и при следующих визитах не теряется, пока пользователь не очистит сохранённые данные сайта; сохранённое ранее «по количеству всего» читается как «по умолчанию». В приватном режиме запись может быть недоступна.
- **Вид списка** — в меню «⋯» шапки группа **Вид**: **Список** (колонка карточек на всю ширину контейнера) и **Карточки** (сетка: не больше 2 колонок при ширине до 768px и не больше 3 начиная с 768px). Порог обоих видов — число за сегодня больше нуля или нет; записи за другие дни вид кнопки не меняют. Пока счётчики грузятся, кнопка — пустой кружок, без «Отметить», галочки и ложного нуля. Если за сегодня 0: в списке только название и кружок на кнопке; в сетке кружок и текст «Отметить». Если за сегодня больше 0: в списке под названием серое число, на кнопке галочка; в сетке на кнопке галочка и число. В обоих видах цифры прокручиваются до итога около 600 мс и при следующем изменении числа тоже; если итог 0, прокрутки нет; при отключённой анимации в системе число сразу итоговое. В сетке название в одну строку, длинное обрезается многоточием. Если дел меньше, чем колонок, карточка занимает одну ячейку. Действия те же (переход в дело и добавление записи). Режим хранится в **`localStorage`** (`log-life:deeds-list-view`), по умолчанию список; после обновления страницы не теряется, пока не очищены данные сайта. В приватном режиме запись может быть недоступна.
- **Действия с карточкой** — только два варианта при взаимодействии с карточкой дела:
  - **Переход в дело** — открытие страницы просмотра дела ([14-screen-deed-view.md](14-screen-deed-view.md)) (эмодзи, название, описание, история записей; оттуда доступны редактирование и удаление дела).
  - **Добавить запись** — обычно переход на экран заполнения формы ([09-screen-fill-form.md](09-screen-fill-form.md)). Если включено **быстрое добавление** и заданы дефолты для всех блоков ([08-screen-create-edit-deed.md](08-screen-create-edit-deed.md)), короткое нажатие кнопки создаёт запись с дефолтами; удержание — форма (как на [экране дела](14-screen-deed-view.md)). Пока запрос идёт, на кнопке спиннер; отдельной зелёной галочки успеха нет. При ошибке быстрого добавления — сообщение под карточкой.
- **Создание нового дела** — кнопка или действие «+ Создать дело» / «+ Добавить дело», переход на экран создания/редактирования дела (новая форма).
- **Профиль** — переход на страницу профиля (авторизация, экспорт данных — см. [12-screen-profile.md](12-screen-profile.md)). На мобильных доступен также через нижнюю панель вкладок ([15-layout-navigation.md](15-layout-navigation.md)).

## Навигация

- Со списка дел пользователь может перейти на экраны: страница просмотра дела ([14-screen-deed-view.md](14-screen-deed-view.md)), создание/редактирование дела ([08-screen-create-edit-deed.md](08-screen-create-edit-deed.md)), заполнение формы ([09-screen-fill-form.md](09-screen-fill-form.md)), профиль ([12-screen-profile.md](12-screen-profile.md)). История записей отображается на странице просмотра дела.
- На мобильных устройствах список дел является одной из вкладок нижней панели («Дела»); переход к списку дел возможен по этой вкладке с любого экрана в контексте дел и записей.

## Загрузка и обратная связь

- Пока подгружаются данные для счётчиков (второй запрос после списка дел), кнопка — пустой кружок. Число за сегодня и подпись «Отметить» появляются только после загрузки, и только если за сегодня больше нуля (в карточках при нуле — «Отметить»).
- При **быстром добавлении записи** с карточки: индикатор ожидания на кнопке появляется не раньше чем через **300 ms** после нажатия; после появления крутится **не меньше 500 ms** (чтобы не мигать на быстрых ответах сервера). Зелёная галочка успеха не показывается.
