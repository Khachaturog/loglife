# 04. Сущность «Запись»

## Определение

Запись — один момент заполнения формы по конкретному делу. Одна запись соответствует одной отправке формы и хранит ответы по всем блокам этого дела.

## Состав записи

### Ответы по блокам

Для каждого блока дела в записи сохраняется ответ в соответствии с типом блока:

- **Число** — одно число.
- **Текст (абзац)** — текст (в т.ч. с переносами строк).
- **Один из списка** — один выбранный вариант.
- **Несколько из списка** — набор выбранных вариантов.
- **Шкала** — выбранное значение на шкале.
- **Да/Нет** — факт «выполнено» / «не выполнено» (в интерфейсе — чекбокс; при просмотре — неактивный чекбокс и подпись).
- **Ссылка URL** — адрес; на просмотре записи открывается в новой вкладке.

### Связь с делом

Каждая запись привязана ровно к одному делу. По делу можно получить список всех записей (история). При редактировании дела (переименование, добавление/удаление блоков, смена типа блока) поведение данных в старых записях описано в [13-rules-editing-deed-data.md](13-rules-editing-deed-data.md).

На экране просмотра записи (`/records/:id`) в шапке:

- Кнопки закреплённых действий дела (`deeds.record_header_pinned`, вкладка «Быстрый доступ» на форме дела). По умолчанию закреплено **Редактировать**. Меню «⋯» при этом содержит все действия каталога, в том числе уже закреплённые.
- **Дублировать** — переход на заполнение формы `/deeds/:deedId/fill` с **теми же ответами по блокам**, что у просматриваемой записи (учитываются только блоки, которые есть у дела сейчас). **Дата и время новой записи** на форме — **текущие** на момент открытия (как при обычном добавлении), а не из исходной записи.
- **Новая запись** — переход на ту же форму **без** предзаполнения ответов.
- **Удалить** и **Справка** — тоже из этого набора: всегда в меню «⋯», и кнопкой в шапке, если закреплены.
- **Перейти к делу** всегда есть в меню «⋯». Отдельная кнопка в шапке — только если запись открыта с вкладки «История» (см. [10-screen-history.md](10-screen-history.md)).
- **Настроить действия** внизу меню «⋯» открывает форму дела на вкладке «Быстрый доступ». И сохранение, и крестик возвращают на эту запись.
- Порядок пунктов меню «⋯»: **Перейти к делу**, затем **Новая запись** и **Дублировать**, затем **Редактировать**, **Удалить**, **Справка**. Между этими группами — разделитель. **Настроить действия** — последним пунктом, тоже после разделителя.

### Превью в списках (история, список записей по делу)

Если у дела **все** активные блоки имеют тип «Да/Нет», в превью строки записи показывается **«N из M»** — сколько блоков отмечено как выполненные (`yesNo: true`) из общего числа таких блоков. Иначе превью — краткие фрагменты ответов по блокам, склеенные через « · ».

### Служебные поля

У каждой записи есть технические поля, общие для всех дел:

- Дата добавления записи.
- Время добавления записи.
- Блок «Заметки» — технический блок внизу формы (свободный текст на всякий случай).
