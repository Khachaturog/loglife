# 04. Сущность «Запись»

## Определение

Запись — один момент заполнения формы по конкретному делу. Одна запись соответствует одной отправке формы и хранит ответы по всем блокам этого дела.

## Состав записи

### Ответы по блокам

Для каждого блока дела в записи сохраняется ответ в соответствии с типом блока:

- **Число** — одно число.
- **Текст (абзац)** — текст (в т.ч. с переносами строк). На просмотре записи переносы сохраняются.
- **Один из списка** — один выбранный вариант.
- **Несколько из списка** — набор выбранных вариантов.
- **Шкала** — выбранное значение на шкале.
- **Да/Нет** — факт «выполнено» / «не выполнено» (в интерфейсе — чекбокс; при просмотре — неактивный чекбокс и подпись).
- **Ссылка URL** — адрес; на просмотре записи одна строка с «…», если не помещается, и открывается в новой вкладке. Полный адрес — в подсказке при наведении и по кнопке «Копировать».
- **Картинка** — квадрат 100×100. Файл в Storage, в ответе только путь. На просмотре записи нажатие на квадрат открывает его в квадратной модалке: сторона — 90% меньшей стороны экрана, но не больше 500px; фото заполняет окно без пустых полос. На превью курсор zoom-in, на развёрнутой картинке — zoom-out. Открытие и закрытие — с анимацией масштаба. Закрывается нажатием в любом месте — по фото или по затемнению вокруг. В списке записей первая включённая в превью картинка стоит слева от текста и в строку ответов не входит.

### Связь с делом

Каждая запись привязана ровно к одному делу. По делу можно получить список всех записей (история). При редактировании дела (переименование, добавление/удаление блоков, смена типа блока) поведение данных в старых записях описано в [13-rules-editing-deed-data.md](13-rules-editing-deed-data.md).

На экране просмотра записи (`/records/:id`) у поля с данными (название дела, дата и время, ответ блока, в том числе устаревший или у удалённого блока) при наведении появляется кнопка **Копировать** — в буфер попадает тот же текст, что виден на экране. Пустое поле и прочерк кнопку не получают. На ширине до 768px кнопки нет. В режиме правки её нет.

На экране просмотра записи (`/records/:id`), пока запись не редактируется, потянуть страницу вниз от верхнего края — заново загрузить запись, дело и конфиги версий. В режиме правки жест выключен и черновик не затирается. См. [15-layout-navigation.md](15-layout-navigation.md).

На экране просмотра записи (`/records/:id`) в шапке:

- Кнопки закреплённых действий дела (`deeds.record_header_pinned`, вкладка «Быстрый доступ» на форме дела). По умолчанию закреплено **Редактировать**. Меню «⋯» при этом содержит все действия каталога, в том числе уже закреплённые.
- **Дублировать** — переход на заполнение формы `/deeds/:deedId/fill` с **теми же ответами по блокам**, что у просматриваемой записи (учитываются только блоки, которые есть у дела сейчас). **Дата и время новой записи** на форме — **текущие** на момент открытия (как при обычном добавлении), а не из исходной записи.
- **Новая запись** — переход на ту же форму **без** предзаполнения ответов.
- **Удалить** и **Справка** — тоже из этого набора: всегда в меню «⋯», и кнопкой в шапке, если закреплены.
- **Перейти к делу** всегда есть в меню «⋯». Отдельная кнопка в шапке — только если запись открыта с вкладки «История» (см. [10-screen-history.md](10-screen-history.md)).
- **Настроить действия** внизу меню «⋯» открывает форму дела на вкладке «Быстрый доступ». И сохранение, и крестик возвращают на эту запись.
- Порядок пунктов меню «⋯»: **Перейти к делу**, затем **Новая запись** и **Дублировать**, затем **Редактировать**, **Удалить**, **Справка**. Между этими группами — разделитель. **Настроить действия** — последним пунктом, тоже после разделителя.
- В режиме **Редактирование** в шапке галочка сохранения. Пока запрос идёт, на ней спиннер и она недоступна.

### Превью в списках (история, список записей по делу)

В превью попадают ответы блоков с `blocks.show_in_preview` (по умолчанию все). Картинка в эту строку не входит: первая включённая в превью картинка показывается квадратом слева. Если выключены все блоки, в строке «—».

Если **все блоки превью** имеют тип «Да/Нет» (скрытые и удалённые не считаются), показывается **«N из M»** — сколько из этих блоков отмечено как выполненные (`yesNo: true`). Иначе превью — краткие фрагменты ответов по включённым блокам, склеенные через « · ». Названия полей в строку не добавляются.

Если заполнены не все текущие блоки дела и у дела включён счётчик (`deeds.fill_counter_enabled`, по умолчанию да), в правом нижнем углу карточки серым показывается **«заполнено/всего»**, например `4/5`. В знаменатель входят все блоки без `deleted_at`, в том числе скрытые из превью. Дата и время в счёт не входят. Пустой текст, число `0`, пустой выбор, пустая ссылка и картинка без файла — незаполненное поле; ответ «Нет» у «Да/Нет» — заполненное. Если пустых полей нет, подпись есть только при `deeds.fill_counter_show_complete` (например `5/5`; по умолчанию выключено). Если счётчик выключен или у дела нет блоков, подписи нет. Это не строка **«N из M»**: та считает только отмеченные «да».

### Служебные поля

У каждой записи есть технические поля, общие для всех дел:

- Дата добавления записи.
- Время добавления записи.
- Блок «Заметки» — технический блок внизу формы (свободный текст на всякий случай).

Подробнее см. [11-technical-defaults.md](11-technical-defaults.md).
