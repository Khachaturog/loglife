# 03. Типы блоков вопрос-ответ

Каждый блок в деле имеет тип, который определяет способ ввода и отображения ответа.

## Число

Человек вводит одно числовое значение (целое или дробное). Пример: «Приседаний: 10», «Вес: 72.5 кг».

- Один инпут для числа; значение по умолчанию в редакторе дела подчиняется тем же правилам валидности, что и при сохранении (ненулевое конечное число).
- Необязательная единица измерения хранится в `blocks.config.unit`. В редакторе дела это выпадающий список: «Нет единицы», пресеты по группам, затем **«Валюта»** и группа **«Другое»** со **«Свой вариант»**. У валюты в скобках международный код (`RUB`), у остальных — символ (`кг`). Свой вариант открывает под списком два поля в одну строку: полное название (до 24 символов) и сокращение (до 8). Оба пишутся строчными буквами. `{ "kind": "custom", "label": "чашки", "short": "чаш" }`. Пустое сокращение в базу не пишется; тогда к числу подставляется полное название. Пресет: `{ "kind": "preset", "code": "kg" }`. Пустое своё название в базу не пишется.
- При вводе числа иконка единицы стоит слева внутри поля (при наведении — полное название), справа — короткое текстовое обозначение: символ пресета (`кг`) или сокращение валюты (`руб`). Свой вариант — иконка информации и своё сокращение. В просмотре, истории и экспорте число подписывается тем же текстом. На чипах недавних значений — только число. Смена единицы не пересчитывает уже сохранённые ответы: в базе остаётся число, меняется только подпись.

Все пункты списка. Код пресета стабильный, подпись и иконка на экране считаются из него. У «Нет единицы» поля `unit` нет. У своего варианта нет кода пресета.

## Текст (абзац)

Свободный текст: короткий или длинный, с переносами. Многострочное поле: по умолчанию по высоте как одна строка, при вводе растёт по содержимому до лимита, затем прокрутка внутри поля.

## Один из списка

Пользователь при настройке блока добавляет варианты ответа. При заполнении формы выбирается только один вариант.

- Варианты в списке можно упорядочивать (см. [05-rules-ordering.md](05-rules-ordering.md)).
- При заполнении новой записи и при редактировании записи выбор — **выпадающий список** (один вариант). На экране просмотра ответ показывается строкой текста.
- В `blocks.config` для этого типа хранится **`singleSelectUi`**. Новые и сохранённые дела пишут `"select"`. Старое значение `"checkbox"` на формах не показывается и при следующем сохранении дела заменяется на `"select"`.

## Несколько из списка

Пользователь добавляет варианты ответа. При заполнении можно выбрать любое количество вариантов.

- Варианты в списке можно упорядочивать в рамках блока.

## Шкала

Пользователь задаёт количество делений на шкале (максимум 10 делений). В настройках дела можно задать подписи для делений (в т.ч. для всех промежуточных — через «Заполнить все подписи»), чтобы ориентироваться при ответе.

- Пример: шкала от 1 до 5 с подписями «Плохо» и «Отлично».
- При заполнении и редактировании записи: если в конфиге есть **хотя бы одна** непустая подпись, под сегментами показывается строка с подписью выбранного деления (или число, если для этой позиции подпись не задана); пока значение не выбрано — подсказка «Выберите значение». Если подписей нет — показывается только сегментированный ряд с цифрами, без дополнительной строки.
- В просмотре записи и при экспорте при наличии подписей значение может отображаться в виде «n — подпись».

## Да/Нет

Факт отметки без ввода значения. Подходит для вопросов вида «сделал ли я задачу», «выполнено ли».

- При ответе один чекбокс с подписью «Выполнено»: включён — да, выключен — нет.
- На экране просмотра записи — неактивный чекбокс и текст «Выполнено» или «Не выполнено».

## Время

Длительность в формате `ЧЧ:ММ:СС` (например время тренировки). При заполнении формы и при редактировании ответа рядом с полем есть кнопка секундомера: модалка открывается с времени из поля, «Старт» продолжает отсчёт, «Сброс» начинает с нуля. В поле время записывается только по «Сохранить». Клик вне окна отсчёт не прерывает.

## Ссылка URL

Один адрес. При заполнении и редактировании — однострочное поле. На экране просмотра записи адрес показан одной строкой: если не помещается, хвост уходит в «…». Клик открывает его в новой вкладке. В ссылку попадают только `http` и `https`; если схемы нет, но строка похожа на адрес, подставляется `https://`. Иные схемы остаются обычным текстом.

## Картинка

Квадрат, по которому запись можно узнать в списке. В одном деле таких блоков может быть несколько.

- На экране квадрат **100×100**. Файл — **WebP до 200×200** (чтобы на ретине не мылился); если на этой стороне он больше 24 КБ, сторона уменьшается (160, 128, 96). Обычно 4–12 КБ и не больше 24 КБ. Оригинал с телефона на сервер не уходит: перед сохранением браузер обрезает центр кадра в квадрат и сжимает. Подходят JPEG, PNG, WebP и HEIC с айфона. Safari на айфоне с холста отдаёт PNG и не уменьшает качество, поэтому WebP там собирается отдельным кодировщиком; потолок тот же, 24 КБ.
- Файл лежит в приватном бакете Storage `record-images`, путь `{user_id}/{record_id}/{block_id}.webp`. В ответе только путь: `{ "imagePath": "..." }`.
- В карточке записи (страница дела и вкладка «История») слева показывается **первая по порядку** картинка, у которой есть файл и включено превью. В текстовую строку ответов картинка не входит. На просмотре записи нажатие на квадрат открывает квадратную модалку (сторона — 90% меньшей стороны экрана). Закрывается нажатием в любом месте: по фото или по затемнению вокруг.
- Значения по умолчанию нет. Обязательная картинка не даёт включить быстрое добавление записи. Необязательная его не блокирует.
- Смена типа на «Картинка» и с «Картинки» ответы автоматически не переносит.

## Общее для всех блоков

- У каждого блока есть настройка **«Обязательное значение»** (да/нет). См. [06-rules-required.md](06-rules-required.md).
- Опционально: **значение по умолчанию** — колонка `blocks.default_value` (формат как ответ в записи); флаг **`blocks.default_value_enabled`** — подставлять ли его при открытии формы новой записи (при выкл. значение в БД сохраняется как черновик). Пользователь может подправить поле перед сохранением.
- Для типов **«Число»** и **«Один из списка»**: переключатель **подсказок из недавних записей** (чипы; колонка `blocks.recent_suggestions_enabled`, по умолчанию включено).
- **Превью в истории** — колонка `blocks.show_in_preview` (по умолчанию включено). Карточки-чекбоксы на вкладке «Превью» в редакторе дела. Выключенный блок не попадает в строку превью записи на странице дела и во вкладке «История». Новый блок включается, пока его не выключат.
- Блоки можно перемещать в нужном порядке относительно друг друга. См. [05-rules-ordering.md](05-rules-ordering.md).
